# References

This directory records the sources used for the reproduction.

The downloaded PDFs and extracted full-text files are kept only in the local
workspace and are intentionally excluded from GitHub.  The repository includes
only citation metadata, source-audit notes, retrieval history, and short
project-specific extracts so that the mathematical route and provenance remain
reviewable without publishing copyrighted source files.

See:

- `REFERENCE_INDEX.md` for bibliographic anchors and DOI information.
- `SOURCE_AUDIT.md` for completeness checks and line anchors used in the
  blueprint.
- `MISSING_SOURCES.md` for the resolved source-acquisition history.
